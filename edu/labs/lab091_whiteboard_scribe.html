Lab 091: Classroom Whiteboard & Scribe

A dedicated classroom demonstration chalkboard! Enter any even number $N$, and watch the automated Smart Scribe execute and narrate each mathematical step of the Goldbach decomposition in real time.

Classroom Mode: INTERACTIVE LECTURE
Lesson: Decomposing Even N = 48

✨ The Teacher's Scribe Tool

In a classroom setting, showing students a finished list of prime pairs can obscure the process of discovery.

This Smart Scribe models the exact mathematical algorithm that students should internalize:

  1. Parity Check: Confirming $N$ is even ($N \equiv 0 \pmod 2$).
  2. Symmetric Bound: Restricting the search space to primes $p \le N/2$ to avoid duplicate unordered pairs.
  3. Complement Testing: Calculating $q = N - p$ and testing $q$ for primality.
  4. Synthesis: Collecting and displaying all valid representations with modular notes.

🎯 Try This! (Hands-On Challenges)

Challenge 1 Scribe $N = 48$. Why does the scribe stop testing candidate primes at $p = 23$?
Because $48 / 2 = 24$. Any prime $p > 24$ would simply produce a duplicate pair $(p, q)$ that was already tested as $(q, p)$!
Challenge 2 Test $N = 100$. How many Goldbach pairs are revealed on the chalkboard?
100 has exactly 6 pairs: $3+97, 11+89, 17+83, 29+71, 41+59, 47+53$.
Challenge 3 Use this whiteboard to lead an interactive peer lesson explaining the multiple-of-6 bonus for 48 ($48 = 6 \times 8$).
Point out that because $3 \mid 48$, no candidate prime $p \equiv 1$ or $5 \pmod 6$ is algebraically blocked by modulo 3 congruences, yielding a rich harvest of 5 pairs!

📐 Algorithmic Search Specification

The standard deterministic pair extraction algorithm:

S(2k) = \{ (p, 2k - p) \mid p \in \mathbb{P}, 2 \le p \le k, \text{ and } (2k - p) \in \mathbb{P} \}

Using a bit-sieve lookup for primality testing, the algorithm runs in time $\mathcal{O}(\pi(k)) = \mathcal{O}(k / \ln k)$ space and steps, optimal for classroom real-time display.
