✨ Symmetry and Anti-Diagonals

Because addition is commutative ($p_i + p_j = p_j + p_i$), the Goldbach matrix is strictly symmetric across the main diagonal: $M = M^T$.

The main diagonal contains doubled primes ($2p$). The anti-diagonals connect prime pairs that sum to the same value $N$.

When you select an even number like 48, you can see all cells with value 48 lighting up across the grid ($5+43, 7+41, 11+37, 17+31, 19+29$). Goldbach's conjecture simply states that every even number $\ge 4$ must appear at least once in this matrix!

Challenge 1 Highlight $N = 30$. How many cells light up in the 25×25 matrix?
30 has 3 unordered pairs: $(7, 23), (11, 19), (13, 17)$. Since $p \ne q$, each pair appears in 2 symmetric positions, illuminating 6 cells!
Challenge 2 Why does $N = 14$ only light up 4 cells ($3+11$ and $7+7$)?
Because $14 = 3 + 11 = 11 + 3$ (2 cells) and $14 = 7 + 7$ (which sits right on the main diagonal, so it only occupies 1 cell!). Total: 3 cells.
Challenge 3 Hover across row 1 (Prime = 2). Why are all entries in this row odd except the very first one?
$2 + \text{Odd Prime} = \text{Odd Number}$! Row 1 and Column 1 are the only paths to produce odd sums in the entire matrix.

📐 Additive Rank & Spectral Trace

Let $P_K = (p_1, \dots, p_K)^T \in \mathbb{R}^K$ and $\mathbf{1} = (1, \dots, 1)^T$. The Goldbach sum matrix can be decomposed as an outer sum:

M = P_K \mathbf{1}^T + \mathbf{1} P_K^T

Consequently, $M$ has algebraic rank at most 2. Its spectral trace is $\operatorname{Tr}(M) = 2 \sum_{i=1}^K p_i$. The pre-image fiber $M^{-1}(N)$ has cardinality equal to the ordered Goldbach count $r_2(N)$.
